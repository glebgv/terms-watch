# Архитектура

## Три слоя

| Слой | Где | Что хранит | Публичность |
|------|-----|-----------|-------------|
| Локальный архив | VPS / Docker volume | Полные тексты, HTML, SQLite-история | только владелец |
| Публичные метаданные | этот репо | Хэши, диффы, ссылки на Wayback | все |
| Витрина + ИИ | GitHub Pages + MCP | Диффы, таймлайн, поиск, чат | все |

## Поток данных

```
[целевые сайты] → (ежедневно 09:00 UTC, Playwright)
  → нормализация + SHA-256
  → [локальный архив: полные тексты, SQLite]
  → дифф (difflib) → если change_ratio > 0.6: is_major, дифф не публикуется
  → [этот репо: data/*.json, changelog.json, feed.xml] (git push)
  → GitHub Pages (витрина) + MCP-сервер
  → RSS / Telegram
```

## Структура данных

См. `data/schema.json`. Сайт = `data/{site_id}/`, документ = `data/{site_id}/{doc_id}/`
с `meta.json`, `versions.json`, `diffs/{date}.json`.

## Правила вежливости монитора

- User-Agent: `TermsWatchBot/1.0 (+https://github.com/glebgv/terms-watch)`
- Уважение robots.txt
- Не чаще 1 запроса/сек на домен
- 3 ретрая с экспоненциальной задержкой

## Юридическая модель

Публикуются только: хэши, диффы-цитаты (ст. 1274 ГК РФ), ссылки на Wayback,
саммари, метаданные. Полные тексты не покидают приватный архив. Диффы с
change_ratio > 0.6 (переписан весь документ) не публикуются — только саммари и
ссылка на первоисточник.
