# terms·watch

Мониторинг изменений пользовательских соглашений, оферт и политик
конфиденциальности сайтов для поиска работы и облачных сервисов
(HeadHunter, Habr Career, Profi.ru, VK, Yandex, SuperJob, Selectel,
Cloud.ru, Timeweb).

**Витрина:** https://glebgv.github.io/terms-watch/

## Что здесь публикуется

- хэши SHA-256 всех зафиксированных версий (`data/{site}/{doc}/versions.json`)
- диффы изменений «было → стало» — цитирование в информационных целях
  (ст. 1274 ГК РФ), не более фрагментов
- метаданные и AI-саммари изменений (`data/changelog.json`, `data/index.json`)
- статус проверок (`data/health.json`)

Полные тексты документов, HTML- и MHTML-слепки хранятся только в приватном
архиве владельца и **никогда** не публикуются.

## Как обновляются данные

Приватный бэкенд (Docker) ежедневно проверяет документы; при изменениях —
автоматический push в `data/` этого репо, далее GitHub Actions пересобирает
витрину. Если данные на витрине старше 48 часов — сверху появляется плашка
«нет синхронизации с бэкендом».

## Витрина

React + Vite + Tailwind (каталог `site/`). Сборка: `cd site && npm ci && npm run build`.
